# Portfolio BTS SIO - Option SISR

Portfolio statique professionnel pour un étudiant en BTS SIO (Services Informatiques aux Organisations) option SISR (Solutions d'Infrastructure, Systèmes et Réseaux).

## 📋 Description

Site portfolio statique développé en HTML5, CSS3 et JavaScript vanilla. Le design est orienté IT/réseaux avec un thème sombre professionnel.

## 🚀 Technologies utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Design responsive avec Flexbox et Grid
- **JavaScript** - Validation de formulaire et navigation mobile

## 📁 Structure du projet

```
PORTFOLIO/
├── index.html          # Page d'accueil
├── experience.html     # Expérience professionnelle
├── projets.html        # Projets techniques SISR
├── cv.html            # CV en HTML
├── contact.html       # Formulaire de contact
├── styles.css         # Fichier CSS principal
├── script.js          # Fichier JavaScript
└── README.md          # Documentation du projet
```

## 🎨 Fonctionnalités

- ✅ Design responsive (mobile, tablette, desktop)
- ✅ Navigation fluide entre les pages
- ✅ Menu hamburger pour mobile
- ✅ Validation de formulaire en temps réel
- ✅ Thème IT/réseaux professionnel
- ✅ Code commenté et structuré

## 📝 Pages du site

1. **Accueil** - Présentation et compétences clés
2. **Expérience** - Détails de l'alternance en entreprise
3. **Projets** - Projets techniques SISR détaillés
4. **CV** - Curriculum Vitae complet en HTML
5. **Contact** - Formulaire de contact avec validation

## 🛠️ Installation et utilisation

1. Clonez le dépôt :
```bash
git clone [URL_DU_REPO]
```

2. Ouvrez `index.html` dans votre navigateur web

Aucune installation de dépendances nécessaire - le site fonctionne directement dans le navigateur.
